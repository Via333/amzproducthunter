# 收藏与单品研究工作台

## 使用入口

- 本机入口：`http://127.0.0.1:8765/index.html#shape-validation`。
- 类目下面先按产品用途分组，再展开材质、结构等具体形态。每个形态独立保留统计、判断和参考 ASIN。
- 点击具体 ASIN 旁的书签收藏，不调用 Sorftime；可在“收藏与研究”集中查看。
- 点击“单品研究”后保存到本机队列，依次运行 `refresh_product_research.py --asin ASIN`，完成后显示“查看研究”。不是向当前聊天发送消息，也不依赖聊天保持运行。
- 已有研究直接查看，不自动覆盖人工复核过的档案。研究页生成不代表专利、合规、供应链或利润已通过验证；这些证据仍依照原研究要求补齐。
- 排队中的任务可以取消；失败、中断的任务可手动重试。运行中不提供强制取消按钮，避免破坏正在写入的研究档案。

## 手动舍弃与恢复

- 2026-09-06：产品验证列表的整组、产品组和形态标题右侧新增舍弃图标，悬停可看操作范围；机会池也可舍弃具体形态。
- 舍弃后同时从候选验证与机会池隐藏，不改评分、不把人工决定伪装成系统风险排除。单个形态被舍弃不影响同组其他形态；舍弃上级组则隐藏其下全部形态。
- 在“收藏与研究”的“已舍弃”标签中恢复。恢复子形态不能越过仍被舍弃的上级组，必要时同时恢复上级。
- 按产品用途与形态稳定标识保存，不按排名、扫描批次或来源类目保存；同一标识下次扫描出现时继续隐藏。分类标识改变后的映射需要另行复核，不能只按显示名称猜测继承。
- 本机服务将记录持久保存于 `.local/research-workbench.sqlite3` 的 `dismissals` 表；恢复只改变状态，不删除历史行。离线或静态网页暂存当前浏览器，连接同源本机服务后同步；不同设备、域名、浏览器之间的离线记录不自动共享，不上传 GitHub。
- 舍弃不删除原始数据、研究档案或收藏，不取消研究队列，也不自动跳过未来扫描；若需要停止扫描，应单独修改有理由、有范围的扫描排除规则。
- 保存失败会提示且不隐藏；仅离线暂存时明确提示保存范围。点击舍弃、恢复和浏览列表不调用 Sorftime。

## 分类与证据

- `product_family.py` 先根据明确的商品标题用途归组，再按材质/结构细分。仅凭 `kitchen tools`、`plumbing fixture` 等泛化标签不能认定同款，无法识别的保留为“用途待确认”。
- `product_family`、`product_form` 是稳定机器标识；中文分别放在 `product_family_label`、`product_form_label`，避免中文被旧归档规范化逻辑清空后发生键冲突。
- `category_shape_validation.py` 先分产品、再分形态、最后重新计算成员统计与原有评分。不能把旧混合分组分数复制给拆出来的每个形态，也不取多个形态的最高分当整组结论。
- 不改写经营排除政策。类目、产品组、形态中被排除的结果默认折叠，搜索或筛选排除结论时仍可展开查看原因与历史。
- 当前分组为标题级初分，不是全部商品完成视觉/SKU 校验。`legacy_form` 是尚未细化的旧形态，不能宣称全部产品已语义归并。
- 同一 ASIN 跨类目出现时收藏与任务按 ASIN 去重；类目统计仍按各自 Top100 保留，不混合不同类目的证据。
- `dashboard_catalog.py` 仅从已有 Top100 和研究数据取标题/图片，不为浏览页面发起 Sorftime 请求；缺图明确留空。

## 保存与运行

- 单品研究新增“颜色、尺寸与 Pack 研究”：只比较当前同用途下各自形态，颜色、容量、产品尺寸、主品装数分别分类；优先结构化商品属性，其次标题，缺失和冲突单列。包装尺寸不替代产品尺寸，`2PCS` 等组件件数不直接当作主品装数，也不沿用旧解析器默认的 `1 pack`。示例图片、ASIN、原属性及采集日期可追溯。价格来自原研究快照，分组占比仅为 ASIN 样本占比，不能作为规格销量或消费者偏好。
- 目标变体矩阵保存原始 `Property`，可把 `Color:2 Pack-White` 分成白色和 2-pack。Sorftime `SalesAmount` 是近 15 天内最近一次捕获的页面销量信号；`-1` 显示为缺失，不当作零，不按子体叠加父体月销。子体没有标明的尺寸或数量不从兄弟变体猜测继承。评论颜色只按评论自身属性统计，并对跨采集目标的重复正文、日期和星级去重。
- 新研究通过 `refresh_product_research.py` 默认最多额外 8 次 Sorftime 属性调用，可用 `--dimension-max-calls 0` 禁止额外属性调用；先复用已有详情，再补目标变体第一页和同形态竞品详情。变体不足一页之外的部分会显示覆盖缺口，不自动扩展无限抓取。`--register-existing` 不新增网络请求。分类结果保存在 `dimension_analysis.json`，原数据与结论不被替换。
- “关联商品与组合套装”区分平台同购模块、评论同场景提及和已有配件。新研究额外尝试一次公开 Amazon 商品页读取（20 秒超时，不绕过验证）；只有明确 FBT 模块且含目标 ASIN 才保留关联项，失败不会擦除既有证据。记录 `association_evidence.json` / `association_collection.json`；既有观察更新前保存在 `association_history`。无订单数据时不推断购买比例或“买得最多”，同场景评论与搜索相关性均不能代替同购订单。场景规则位于 `config/bundle_research_rules.json`，当前已覆盖面糊分配瓶；其他用途无匹配规则时明确留空，不生成通用赠品结论。

- 评论证据保留原文，在下方另列中文翻译。译文保存在各研究目录的 `review_translations.json`，`entries` 中每项包含与 `demand_analysis.csv` 完全一致的 `source_excerpt` 和 `translation_zh`；截断摘录另设 `source_truncated: true`，只翻译现有内容。同一原文跨主题复用译文，原文变化后旧译文不再匹配。生成器不调用翻译接口，未补译文明确显示“中文翻译待补充”，不使用主题标签冒充翻译，也不改写原始评论和评分。
- 单品页“已研究样本形态”每行展示一个原研究快照中的示例图片和 ASIN；按原 `product_form` 精确匹配，不使用当前重分组替换历史成员。优先已有图片，其次 seed/direct 样本和月销，ASIN 用于稳定排序；缺图仍保留商品链接。
- 仅补这张表的示例图片：`python3 research_images.py --asin ASIN --scope snapshot --representatives-only --max-calls 20`，运行环境需有 Pillow。每个形态只选择一个样本，优先本地/详情缓存；不改写原产品、形态、评论或研究结论。`--max-calls` 是上限，不代表每次都会调用；默认命令仍补当前同用途图库。

- 服务：`preview_service.py`，由已有 `com.amz-selection.preview` LaunchAgent 管理，只监听 `127.0.0.1:8765`，只发布 `web/`。
- 数据：`.local/research-workbench.sqlite3`，已加入 `.gitignore`。收藏、队列与舍弃记录不会进入 GitHub Pages。
- 日志：`logs/research-job-ID.log`。网页只显示通用失败原因，不暴露日志、MCP 密钥或配置内容。
- 收藏离线时暂存当前浏览器的 `localStorage`；同源本机服务恢复后同步增删。不同浏览器/域名间的离线收藏不自动共享。
- GitHub Pages/file 页面没有 Python 执行服务：可以浏览及本浏览器收藏，不能直接发起研究。执行需要打开本机入口；服务离线时研究按钮禁用，不会暗中攒任务等待恢复后消耗额度。
- 工作进程一次只执行一个研究任务；同 ASIN 活跃任务有数据库唯一约束，重复提交返回原任务。已有页和研究索引同时存在时跳过重新抓取。
- `refresh_product_research.py` 与网页队列共用 `.local/research.lock`，防止通过此入口同时改写研究索引和页面。直接运行底层采集脚本不在这把锁的保护范围内。
- 服务重启保留待执行队列；中断任务不自动重试，避免重复扣额度。若旧进程仍在运行，先等待其退出，不立即执行第二个任务。
- POST 操作要求同源 Origin、合法 Host、JSON 和临时 CSRF token；ASIN 严格限制为 10 位字母数字，执行使用参数数组而非 shell 拼接。
- 2026-09-05 修复内置浏览器误判离线：实测 `Host: 127.0.0.1:8765`、`Origin: http://127.0.0.1`、`Sec-Fetch-Site: same-origin`。仅在浏览器提供 `same-origin` 且 Origin 精确匹配同一回环主机、不带端口时兼容；不放行任意端口、`null`、跨站来源或缺失令牌的提交。不能通过通配 CORS 或取消来源校验解决此问题。
- 形态列表和收藏面板显示连接状态，失败保留具体原因及重连按钮；切回页面、网络恢复时会重新检查，轮询不会并发堆积，也不会因恢复连接自动发起研究。

## 验证

- `python3 -m unittest discover -s tests`。
- `tests/test_research_workbench.py` 覆盖用途分组、形态独立统计、收藏持久化、重复提交、串行执行、取消/重试、中断、已有研究复用、HTTP 来源验证及模拟研究成功生成结果。
- 浏览器测试必须拦截研究接口或使用临时夹具，不为测试消耗真实 Sorftime 请求。已有手工研究和用户利润输入不得覆盖。
- 灰色按钮修复回归：122 项单元测试通过；浏览器以实测缺端口请求头验证接口 200，模拟单次提交、排队禁用、取消、403 禁用与手动重连恢复，检查 1440px/390px 布局。测试结束必须移除请求拦截；真实队列可能同时被用户操作，不得清空或回滚。
- 舍弃功能回归（2026-09-06）：193 项单元测试通过，另用独立临时数据库完成16项浏览器断言，覆盖两个列表同步、刷新、上下级范围、恢复、保存失败、离线暂存及重连同步。1440px/390px截图已检查；不在真实数据库上写测试决定，不启动研究工作进程。
