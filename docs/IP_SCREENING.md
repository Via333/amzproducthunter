# 知识产权初查与上架边界

修订：2026-10-04。初查不是法律意见，不出具“无侵权风险”或全面自由实施保证。

## 必查顺序

1. 锁定实际供应商 SKU、目标国家、销售配置、配件清单、样品及六视图。研究 seed、参考 ASIN 和实际供货 SKU 分开，不允许自动继承放行。
2. 找到原始品牌及制造商；检查官网 Patent/IP/Legal/虚拟专利标记页面，并追溯权利人、关联公司、历史名称。通用品名检索不能代替这一步。
3. 检索功能同义词、外观分类、权利人、相关同族、分案及引用。保存检索式、数据库、日期、命中和未覆盖范围；零命中只是有限检索结果。
4. 分开核查实用专利与外观专利。实用专利需逐要素比对有效权利要求；外观需检查全部附图、实线/虚线及主张的整体视觉外观。不得以改颜色、去 Logo、改 pack 或局部小改动自动通过。
5. 核查文字、图形、三维商标及商业外观，包括内部和随附零部件；另核查照片、包装图文、模型文件版权及授权链。内部钢丝球不因是配件就豁免。
6. 核对 USPTO/相关法域官方权利状态、权利人和转让链，记录当前日期。Google Patents 和聚合站是线索，不是实时有效性证明；状态冲突一律待核。过期的一项权利不排除其他权利。
7. 查投诉、诉讼、无效/撤销程序，区分当事人主张、临时禁令、和解和最终裁判。起诉不等于侵权成立；未检出诉讼不等于安全。
8. 发现相关在权专利或形状权利线索时，先暂停推进，再由合适法域的知识产权专业人员针对实际 SKU 审核覆盖、授权或设计规避；商业决策独立于销量、利润和食品接触合规。

## 状态与程序规则

- 未完成/证据冲突：`pending`，不能称低风险或无风险。
- 有限初查未发现明确冲突：记录具体范围和局限，仍不是上架许可。
- 高风险命中/未解决权利线索：`risk=high, clearance=blocked`，必须显示暂缓立项与上架，不被新品、利润结论覆盖。
- 旧高风险证据过期：要求更新，不能自动清除风险。
- 当前自动研究程序无专业法律审批接口，任何输入的专利 `clear` 都不能直接变成 `launch_clearance`。专业意见应单独保存并人工核验，不能伪装成自动检索已通过。

## 本次事故复盘

面糊瓶研究档案的旧专利状态为 `pending/unknown`，没有 `risk_review.json`，却已进入 Listing 草稿制作。用户报告曾被告知“无侵权风险”；本次未找到该原话，不能虚构历史搜索过程。能证实的是：现有记录没有支持无风险的证据；旧程序只验证来源 URL、日期、ASIN 和 reviewed 标志，便会接受手工 `clear`，没有外观/配件/商标的完整性保证。另有新品分析覆盖高风险结论的可能。

本次修正禁止自动知识产权放行、提高高风险结论优先级，并补录 Whiskware Batter Mixer 的官方专利对应关系。未实施全面 FTO，也未变更卖家后台。
