# 1688 供应商初筛

单品研究页新增 `#supplier-screening`，从已保存的 1688 搜索数据生成供货链接候选。页面的筛选、排序和候选勾选均在浏览器本地运行，不调用 Sorftime。勾选按 Amazon ASIN 保存在当前浏览器，不向商家发送信息，也不跨浏览器同步。

## 数据与边界

- `research_sources.json`：原研究的主图搜索来源。
- `supplier_screening_sources.json`：补充关键词、图片和详情调用的原始响应、参数和采集日期。不得包含账号密钥。
- `supplier_screening.json`：自动采集步骤生成的初筛快照。页面仍按当前原始来源重新构建，不能把页面构建日期当作指标采集日期。
- `supplier_quotes.csv` 与商业可行性验证保持独立。初筛绝不将展示价写入有效采购成本。

按 offer ID 去重；店名缺失时不合并店铺，也不把不同链接声称为不同工厂。标题同用途只证明询价相关性，尺寸、材料和具体 SKU 仍须核对。件数仅是标题提取值，不据此将商品展示价折算成单件采购成本。

商品评分采用有评论数量支持的商品 `score`。服务评分和品质体验单列，不转换成好评率。回头率保留接口的百分比值；接口未说明的周期和分母保持待核。整组零值的空详情不覆盖已有搜索证据，缺失值不冒充零价格。

超级工厂身份只标记为平台工厂标签，不证明自有厂房或生产线；会员、实力商家、店名含“工厂”均不自动算自有工厂。

## 初筛顺序

1. 区分同用途、匹配待核和明确不匹配；已有 SKU 材质不匹配记录优先保留。
2. 低品质体验（低于 3.5/5）或低商品评分（低于 4/5）优先标风险。
3. 同用途、采集未超过 7 天、有效展示价、服务评分至少 4/5、回头率至少 30% 的链接列为“优先询样”，不是已验证供应商。
4. 同一层级再参考平台工厂标签、商品评分、回头率和服务评分。价格独立排序；跨规格排序不代表同规格性价比。

仅少数已知产品方向有中文关键词规则。未知用途保持待核，不靠图片检索排名或源类目强行判定同款。

## 调用与测试

`mcp_product_opportunity_research.py` 自动使用既有主图结果，并通过 `collect_supplier_screening` 最多补 1 次关键词、2 次详情逻辑调用；同一研究 7 天内复用初筛缓存。底层客户端重试仍可能产生额外实际请求。单独构建网页不会调用接口。失败响应保留状态，不保存可能含凭据的异常字符串。

离线测试：`python3 -B -m unittest discover -s tests -p 'test_supplier_screening.py'`。浏览器测试需拦截研究 API，避免消费额度或触发任务。
